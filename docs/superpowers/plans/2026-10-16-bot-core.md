# Bot-Gegner (Bot-Kern) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Host can add computer opponents ("Bots") with a difficulty of Ø 0–180 to the lobby; they play X01 and Cricket as full players by driving a virtual dartboard.

**Architecture:** Pure domain package `game/bot` (board geometry, Gaussian throw model, constant Ø→σ calibration, checkout table, X01/Cricket strategies). Application `application/bot/BotService` observes every `EngineUpdate` (decorator around `GameUpdatePublisherPort`), schedules darts with human-like delays and sends them through a new `VirtualBoardPort`, implemented in infrastructure on top of the existing `ThrowPublisherPort` → MQTT `dartboard/<9xx>`. `GameEngine`, `X01Game`, `CricketGame` and the MQTT input path stay untouched.

**Tech Stack:** Java 21, Gradle, Lombok, Gson, JUnit 5; plain JS for the web UIs.

**Spec:** `docs/superpowers/specs/2026-10-16-bot-core-design.md`

## Global Constraints

- **No git commits.** The user commits; every task ends with a checkpoint, not a commit.
- All commands run from `dart-server/onion-server` (`./gradlew test`, `./gradlew test --tests "<class>"`).
- Code identifiers/comments in English like the surrounding code; user-facing messages (LobbyResult failures, UI text) in **German**.
- Board IDs **900–999 are reserved for bots** (`LobbyPlayer.FIRST_BOT_BOARD_ID` … `LAST_BOT_BOARD_ID`).
- Presets: **Easy Ø 25 · Normal Ø 40 · Hard Ø 60 · Pro Ø 85**; custom 0–180 in steps of 5.
- Strategy intelligence tied to average: **smart = Ø ≥ 40**.
- Bot never produces wall hits (`997`) or bounce-outs (`996`); off-board = `BOARD_HIT` (`998`).
- Timing defaults: dart every 1.5–3.0 s (uniform), `999` 2.5 s after turn end, watchdog 10 s.
- gameUpdate JSON: optional `"bot": true` per player, documented in `dart-server/schema.json` (backward compatible).
- `version` in `dart-server/onion-server/build.gradle` must be bumped (CI rule): `2.2.0` → `2.3.0`.
- `LegacyRun` (`--player`) gets no bot support.

## Review Focus

1. **Solo game, bot alone in the lobby, repeating turns** — the bot's action key `(gameId, playerId, freieWuerfe, state)` repeats every turn; the bot must keep playing turn after turn (covered in Task 7 `soloBotKeepsPlayingAcrossTurns`).
2. **Human presses NEXT / bounce-out on the host board while the bot's `999` is pending** — no duplicate `999`, no extra dart (Task 7 `humanNextCancelsPendingBotNext`, `undoInWaitingKeepsSingleNext`).
3. **Game end by a bot** — in `FINISHED` the bot must send `999` itself, otherwise the tournament hangs waiting (Task 7 end-to-end test + Task 8 session test).
4. **Host tries to rename/re-board a bot** via the normal join path (TV ◀▶ board stepper or same-name join) — must be rejected, bot must stay a bot (Task 8 `joinWithBotNameIsRejected`; Task 10 guards the TV stepper).
5. **Broker down while the bot throws** — dart is dropped by `MqttThrowForwarder`; the watchdog must resend (Task 7 `watchdogResendsWhenThrowGetsLost`).

`BoardGeometry.java`:

```java
package it.tobaben.dart.game.bot;

import it.tobaben.dart.game.board.Segment;

/**
 * Standard dartboard proportions (radii in mm). Only the proportions matter for
 * the bot: the difficulty calibration maps an average to a scatter σ in the
 * same units, so soft-tip vs. steel size does not change the result.
 */
public final class BoardGeometry {

    public static final double BULLSEYE_RADIUS = 6.35;
    public static final double BULL_RADIUS = 15.9;
    public static final double TRIPLE_INNER = 99.0;
    public static final double TRIPLE_OUTER = 107.0;
    public static final double DOUBLE_INNER = 162.0;
    public static final double DOUBLE_OUTER = 170.0;

    /** Clockwise from the top, 18° per sector. */
    static final int[] SECTORS = {20, 1, 18, 4, 13, 6, 10, 15, 2, 17, 3, 19, 7, 16, 8, 11, 14, 9, 12, 5};
    private static final double SECTOR_DEGREES = 18.0;

    private BoardGeometry() {
    }

    /** @return the segment hit at (x, y); everything beyond the double ring is BOARD_HIT (miss) */
    public static Segment segmentAt(double x, double y) {
        double radius = Math.hypot(x, y);
        if (radius <= BULLSEYE_RADIUS) {
            return Segment.BULLS_EYE;
        }
        if (radius <= BULL_RADIUS) {
            return Segment.BULL;
        }
        if (radius > DOUBLE_OUTER) {
            return Segment.BOARD_HIT;
        }
        double degrees = Math.toDegrees(Math.atan2(x, y)); // clockwise from top
        double shifted = ((degrees + SECTOR_DEGREES / 2) % 360 + 360) % 360;
        int number = SECTORS[(int) Math.floor(shifted / SECTOR_DEGREES)];
        if (radius > TRIPLE_INNER && radius <= TRIPLE_OUTER) {
            return segment(3, number);
        }
        if (radius > DOUBLE_INNER) {
            return segment(2, number);
        }
        return segment(1, number);
    }

    /** @return the middle of the segment's field; bull and bullseye are aimed at the centre */
    public static AimPoint centerOf(Segment segment) {
        if (segment == Segment.BULL || segment == Segment.BULLS_EYE) {
            return AimPoint.CENTER;
        }
        int multiplier = segment.getMultiplier();
        if (multiplier == 0) {
            throw new IllegalArgumentException("Kein Zielfeld: " + segment);
        }
        int number = segment.getScore() / multiplier;
        double radius = switch (multiplier) {
            case 3 -> (TRIPLE_INNER + TRIPLE_OUTER) / 2;
            case 2 -> (DOUBLE_INNER + DOUBLE_OUTER) / 2;
            default -> (TRIPLE_OUTER + DOUBLE_INNER) / 2; // outer single field, the larger one
        };
        double radians = Math.toRadians(sectorIndexOf(number) * SECTOR_DEGREES);
        return new AimPoint(radius * Math.sin(radians), radius * Math.cos(radians));
    }

    /** @param number 1–20, or 25 for bull (multiplier 1) / bullseye (multiplier 2) */
    public static Segment segment(int multiplier, int number) {
        if (number == 25) {
            return switch (multiplier) {
                case 1 -> Segment.BULL;
                case 2 -> Segment.BULLS_EYE;
                default -> throw new IllegalArgumentException("Kein Feld: " + multiplier + "x" + number);
            };
        }
        String prefix = switch (multiplier) {
            case 1 -> "SINGLE_";
            case 2 -> "DOUBLE_";
            case 3 -> "TRIPLE_";
            default -> throw new IllegalArgumentException("Kein Feld: " + multiplier + "x" + number);
        };
        return Segment.valueOf(prefix + number);
    }

    private static int sectorIndexOf(int number) {
        for (int i = 0; i < SECTORS.length; i++) {
            if (SECTORS[i] == number) {
                return i;
            }
        }
        throw new IllegalArgumentException("Keine Sektorzahl: " + number);
    }
}
```

`ThrowModel.java`:

```java
package it.tobaben.dart.game.bot;

import it.tobaben.dart.game.board.Segment;

import java.util.Collections;
import java.util.EnumMap;
import java.util.HashMap;
import java.util.Map;
import java.util.Random;

/**
 * How precisely a bot throws: the dart lands at the aim point plus an isotropic
 * 2D normal scatter with standard deviation σ (mm).
 */
public class ThrowModel {

    static final int DISTRIBUTION_SAMPLES = 4000;
    private static final long DISTRIBUTION_SEED = 42;

    private final double sigma;
    private final Random random;
    private final Map<AimPoint, Map<Segment, Double>> distributions = new HashMap<>();

    public ThrowModel(double sigma, Random random) {
        this.sigma = sigma;
        this.random = random;
    }

    public double getSigma() {
        return this.sigma;
    }

    public Segment throwAt(AimPoint target) {
        return BoardGeometry.segmentAt(
                target.x() + this.random.nextGaussian() * this.sigma,
                target.y() + this.random.nextGaussian() * this.sigma);
    }

    /** @return probability per segment when aiming at target (Monte Carlo, fixed seed, cached) */
    public synchronized Map<Segment, Double> distribution(AimPoint target) {
        return this.distributions.computeIfAbsent(target, this::sample);
    }

    private Map<Segment, Double> sample(AimPoint target) {
        Random sampler = new Random(DISTRIBUTION_SEED);
        Map<Segment, Double> result = new EnumMap<>(Segment.class);
        double weight = 1.0 / DISTRIBUTION_SAMPLES;
        for (int i = 0; i < DISTRIBUTION_SAMPLES; i++) {
            Segment hit = BoardGeometry.segmentAt(
                    target.x() + sampler.nextGaussian() * this.sigma,
                    target.y() + sampler.nextGaussian() * this.sigma);
            result.merge(hit, weight, Double::sum);
        }
        if (this.sigma == 0) {
            // exact 1.0 instead of 4000 summed fractions
            result.replaceAll((segment, probability) -> 1.0);
        }
        return Collections.unmodifiableMap(result);
    }
}
```

```java
package it.tobaben.dart.game.bot;

/**
 * Maps the difficulty a host picks (3-dart scoring average 0–180) to the
 * scatter σ of the ThrowModel. The table depends only on the board geometry
 * and the T20 aim point, so it is a constant: generated once by Monte Carlo
 * (2,000,000 darts per row aimed at the T20 centre). DifficultyCalibrationTest
 * re-measures it.
 */
public final class DifficultyCalibration {

    /** {σ in mm, 3-dart average when always aiming at T20}, σ ascending. */
    static final double[][] TABLE = {
            {0.0, 180.0},
            {1.0, 180.0},
            {2.0, 174.5},
            {3.0, 158.1},
            {4.0, 142.0},
            {5.0, 129.0},
            {6.0, 118.7},
            {7.0, 109.9},
            {8.0, 102.1},
            {9.0, 95.0},
            {10.0, 88.5},
            {12.0, 77.5},
            {14.0, 68.6},
            {16.0, 61.6},
            {18.0, 56.0},
            {20.0, 51.8},
            {22.0, 48.4},
            {25.0, 44.7},
            {28.0, 42.2},
            {31.0, 40.4},
            {35.0, 38.4},
            {40.0, 36.5},
            {45.0, 34.9},
            {50.0, 33.4},
            {60.0, 30.8},
            {70.0, 28.4},
            {80.0, 26.3},
            {90.0, 24.4},
            {100.0, 22.6},
            {120.0, 19.3},
            {140.0, 16.5},
            {170.0, 13.0},
            {200.0, 10.3},
            {250.0, 7.3},
            {300.0, 5.4},
            {400.0, 3.2},
            {600.0, 1.5},
            {1000.0, 0.5},
            {2000.0, 0.1}
    };

    private DifficultyCalibration() {
    }

    /** @return σ for the average, linearly interpolated; averages below the table's end get its largest σ */
    public static double sigmaFor(int average) {
        if (average < 0 || average > 180) {
            throw new IllegalArgumentException("Average muss zwischen 0 und 180 liegen: " + average);
        }
        for (int i = 1; i < TABLE.length; i++) {
            double upperAverage = TABLE[i - 1][1];
            double lowerAverage = TABLE[i][1];
            if (average >= lowerAverage) {
                if (upperAverage == lowerAverage) {
                    return TABLE[i - 1][0];
                }
                double t = (upperAverage - average) / (upperAverage - lowerAverage);
                return TABLE[i - 1][0] + t * (TABLE[i][0] - TABLE[i - 1][0]);
            }
        }
        return TABLE[TABLE.length - 1][0];
    }
}
```

```java
package it.tobaben.dart.game.bot;

/**
 * Difficulty of a bot: its 3-dart scoring average (0–180). From
 * SMART_FROM_AVERAGE on the bot also plays tactically (checkout routes,
 * avoiding Schnapszahlen and bogey numbers).
 */
public record BotProfile(int average) {

    public static final int SMART_FROM_AVERAGE = 40;

    public BotProfile {
        if (average < 0 || average > 180) {
            throw new IllegalArgumentException("Average muss zwischen 0 und 180 liegen: " + average);
        }
    }

    public double sigma() {
        return DifficultyCalibration.sigmaFor(this.average);
    }

    public boolean smart() {
        return this.average >= SMART_FROM_AVERAGE;
    }
}
```

```java
public final class Checkouts {

    private static final Map<Integer, List<Segment>> ROUTES = load();

    private Checkouts() {
    }

    /** @return the route to finish rest with at most dartsLeft darts; first element is the next dart */
    public static Optional<List<Segment>> route(int rest, int dartsLeft) {
        List<Segment> route = ROUTES.get(rest);
        if (route != null && route.size() <= dartsLeft) {
            return Optional.of(route);
        }
        if (dartsLeft >= 1) {
            // e.g. 50 with one dart: the table prefers S10 D20, but the bullseye finishes too
            Segment oneDart = oneDartFinish(rest);
            if (oneDart != null) {
                return Optional.of(List.of(oneDart));
            }
        }
        return Optional.empty();
    }

    static Map<Integer, List<Segment>> routes() {
        return ROUTES;
    }

    private static Segment oneDartFinish(int rest) {
        if (rest == 50) {
            return Segment.BULLS_EYE;
        }
        if (rest >= 2 && rest <= 40 && rest % 2 == 0) {
            return BoardGeometry.segment(2, rest / 2);
        }
        return null;
    }

    private static Map<Integer, List<Segment>> load() {
        Map<String, Segment> byCode = new HashMap<>();
        for (Segment segment : Segment.values()) {
            byCode.put(segment.getCode(), segment);
        }
        Map<Integer, List<Segment>> routes = new HashMap<>();
        try (InputStream in = Checkouts.class.getResourceAsStream(RESOURCE)) {
            if (in == null) {
                throw new IllegalStateException("Ressource fehlt: " + RESOURCE);
            }
            BufferedReader reader = new BufferedReader(new InputStreamReader(in, StandardCharsets.UTF_8));
            String line;
            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (line.isEmpty() || line.startsWith("#")) {
                    continue;
                }
                String[] parts = line.split("\\s+");
                List<Segment> route = new ArrayList<>();
                for (int i = 1; i < parts.length; i++) {
                    Segment segment = byCode.get(parts[i]);
                    if (segment == null) {
                        throw new IllegalStateException("Unbekanntes Feld in " + RESOURCE + ": " + parts[i]);
                    }
                    route.add(segment);
                }
                routes.put(Integer.parseInt(parts[0]), List.copyOf(route));
            }
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
        return Collections.unmodifiableMap(routes);
```

```java
package it.tobaben.dart.game.bot;

import it.tobaben.dart.common.Player;
import it.tobaben.dart.game.GameSnapshot;
import it.tobaben.dart.game.board.Segment;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.Set;
import java.util.function.IntPredicate;

/**
 * X01 tactics. Naive bots score on T20 and walk down to a double; smart bots
 * follow the checkout table, set up preferred doubles and on the last dart of
 * a turn avoid leaving a penalized rest (Schnapszahl, house rule) or a bogey
 * number.
 */
public class X01Strategy implements BotStrategy {

    static final List<Integer> PREFERRED_LEAVES =
            List.of(40, 32, 36, 24, 16, 20, 8, 12, 28, 38, 34, 30, 26, 22, 18, 14, 10, 6, 4, 2);
    static final Set<Integer> BOGEY_NUMBERS = Set.of(169, 168, 166, 165, 163, 162, 159);
    static final double MAX_PENALTY_RISK = 0.15;
    static final double BOGEY_WEIGHT = 0.5;
    private static final List<Segment> SCORING_ALTERNATIVES = List.of(
            Segment.TRIPLE_20, Segment.TRIPLE_19, Segment.TRIPLE_18,
            Segment.SINGLE_20, Segment.SINGLE_19, Segment.SINGLE_18);

    private final boolean smart;
    private final ThrowModel throwModel;
    private final IntPredicate penalizedRest;

    /**
     * @param penalizedRest rests that cost a penalty at the end of a turn
     *                      (Schnapszahl when the house rule is on), evaluated by smart bots only
     */
    public X01Strategy(boolean smart, ThrowModel throwModel, IntPredicate penalizedRest) {
        this.smart = smart;
        this.throwModel = throwModel;
        this.penalizedRest = penalizedRest;
    }

    @Override
    public AimPoint aim(GameSnapshot snapshot, Player self) {
        return BoardGeometry.centerOf(target(snapshot, self));
    }

    Segment target(GameSnapshot snapshot, Player self) {
        Map<String, String> rules = snapshot.modeData();
        int rest = snapshot.scores().get(self);
        int dartsLeft = snapshot.throwsLeftInTurn();
        boolean doubleIn = Boolean.parseBoolean(rules.get("doubleIn"));
        boolean doubleOut = Boolean.parseBoolean(rules.get("doubleOut"));
        int startScore = Integer.parseInt(rules.get("startScore"));

        if (doubleIn && rest == startScore) {
            return Segment.DOUBLE_20;
        }
        if (!this.smart) {
            return doubleOut ? naiveDoubleOut(rest) : straightOut(rest);
        }
        Segment planned = doubleOut ? smartDoubleOut(rest, dartsLeft) : straightOut(rest);
        return dartsLeft == 1 ? avoidPenalties(planned, rest, doubleOut) : planned;
    }

    private static Segment straightOut(int rest) {
        if (rest > 60) {
            return Segment.TRIPLE_20;
        }
        Segment exact = oneDartExact(rest);
        return exact != null ? exact : BoardGeometry.segment(1, Math.min(20, rest - 1));
    }

    private static Segment oneDartExact(int rest) {
        if (rest <= 20) {
            return BoardGeometry.segment(1, rest);
        }
        if (rest == 25) {
            return Segment.BULL;
        }
        if (rest == 50) {
            return Segment.BULLS_EYE;
        }
        if (rest % 3 == 0 && rest <= 60) {
            return BoardGeometry.segment(3, rest / 3);
        }
        if (rest % 2 == 0 && rest <= 40) {
            return BoardGeometry.segment(2, rest / 2);
        }
        return null;
    }

    private static Segment naiveDoubleOut(int rest) {
        if (rest > 60) {
            return Segment.TRIPLE_20;
        }
        if (rest == 50) {
            return Segment.BULLS_EYE;
        }
        if (rest % 2 == 0 && rest <= 40) {
            return BoardGeometry.segment(2, rest / 2);
        }
        if (rest > 40) {
            return BoardGeometry.segment(1, rest - 40);
        }
        return Segment.SINGLE_1; // odd rest: make it even
    }

    private static Segment smartDoubleOut(int rest, int dartsLeft) {
        Optional<List<Segment>> route = Checkouts.route(rest, dartsLeft);
        if (route.isPresent()) {
            return route.get().get(0);
        }
        if (rest <= 100) {
            Segment setup = setupFor(rest);
            if (setup != null) {
                return setup;
            }
        }
        return rest - 60 >= 2 ? Segment.TRIPLE_20 : Segment.SINGLE_20;
    }

    /** @return a dart that leaves a preferred double; singles before bull before triples */
    private static Segment setupFor(int rest) {
        for (int leave : PREFERRED_LEAVES) {
            int value = rest - leave;
            if (value >= 1 && value <= 20) {
                return BoardGeometry.segment(1, value);
            }
            if (value == 25) {
                return Segment.BULL;
            }
            if (value >= 3 && value <= 60 && value % 3 == 0) {
                return BoardGeometry.segment(3, value / 3);
            }
        }
        return null;
    }

    private Segment avoidPenalties(Segment planned, int rest, boolean doubleOut) {
        List<Segment> candidates = new ArrayList<>();
        candidates.add(planned);
        for (Segment alternative : SCORING_ALTERNATIVES) {
            // no deliberate bust (v1): alternatives must not bust on a direct hit
            if (!candidates.contains(alternative) && !bustsOnHit(alternative, rest, doubleOut)) {
                candidates.add(alternative);
            }
        }
        Segment best = planned;
        double bestRisk = Double.MAX_VALUE;
        for (Segment candidate : candidates) {
            double risk = penaltyRisk(candidate, rest, doubleOut);
            if (risk < MAX_PENALTY_RISK) {
                return candidate;
            }
            if (risk < bestRisk) {
                best = candidate;
                bestRisk = risk;
            }
        }
        return best;
    }

    double penaltyRisk(Segment target, int rest, boolean doubleOut) {
        double risk = 0;
        for (Map.Entry<Segment, Double> outcome
                : this.throwModel.distribution(BoardGeometry.centerOf(target)).entrySet()) {
            Segment hit = outcome.getKey();
            if (bustsOnHit(hit, rest, doubleOut)) {
                continue; // bust: score back to turn start, no penalty
            }
            int after = rest - hit.getScore();
            if (this.penalizedRest.test(after)) {
                risk += outcome.getValue();
            } else if (doubleOut && BOGEY_NUMBERS.contains(after)) {
                risk += BOGEY_WEIGHT * outcome.getValue();
            }
        }
        return risk;
    }

    private static boolean bustsOnHit(Segment hit, int rest, boolean doubleOut) {
        int after = rest - hit.getScore();
        if (after < 0) {
            return true;
        }
        return doubleOut && (after == 1 || (after == 0 && hit.getMultiplier() != 2));
    }
}
```

```java
package it.tobaben.dart.game.bot;

import it.tobaben.dart.common.Player;
import it.tobaben.dart.game.GameSnapshot;

import java.util.List;

/**
 * Cricket tactics. Naive bots close 20 → 15 → bull in order. Smart bots score
 * on their closed numbers while behind, block numbers an opponent already
 * closed, and otherwise close the highest open number.
 */
public class CricketStrategy implements BotStrategy {

    static final List<Integer> NUMBERS = List.of(20, 19, 18, 17, 16, 15, 25);
    private static final int CLOSED = 3;

    private final boolean smart;

    public CricketStrategy(boolean smart) {
        this.smart = smart;
    }

    @Override
    public AimPoint aim(GameSnapshot snapshot, Player self) {
        int number = targetNumber(snapshot, self);
        return number == 25 ? AimPoint.CENTER : BoardGeometry.centerOf(BoardGeometry.segment(3, number));
    }

    int targetNumber(GameSnapshot snapshot, Player self) {
        if (!this.smart) {
            return NUMBERS.stream().filter(n -> marks(snapshot, self, n) < CLOSED).findFirst().orElse(20);
        }
        List<Player> opponents = snapshot.playerOrder().stream().filter(p -> !p.equals(self)).toList();
        int myPoints = snapshot.scores().getOrDefault(self, 0);
        int bestOpponent = opponents.stream()
                .mapToInt(p -> snapshot.scores().getOrDefault(p, 0)).max().orElse(0);
        if (myPoints < bestOpponent) {
            for (int number : NUMBERS) {
                if (marks(snapshot, self, number) >= CLOSED && anyOpen(snapshot, opponents, number)) {
                    return number;
                }
            }
        }
        for (int number : NUMBERS) {
            if (marks(snapshot, self, number) < CLOSED
                    && opponents.stream().anyMatch(o -> marks(snapshot, o, number) >= CLOSED)) {
                return number;
            }
        }
        for (int number : NUMBERS) {
            if (marks(snapshot, self, number) < CLOSED) {
                return number;
            }
        }
        for (int number : NUMBERS) {
            if (anyOpen(snapshot, opponents, number)) {
                return number; // everything closed but still behind: keep scoring
            }
        }
        return 20;
    }

    private static boolean anyOpen(GameSnapshot snapshot, List<Player> players, int number) {
        return players.stream().anyMatch(p -> marks(snapshot, p, number) < CLOSED);
    }

    private static int marks(GameSnapshot snapshot, Player player, int number) {
        return Integer.parseInt(snapshot.modeData()
                .getOrDefault("marks:" + player.getName() + ":" + number, "0"));
    }
}
```

```java
import java.util.concurrent.ScheduledFuture;
import java.util.concurrent.TimeUnit;

/** Production scheduler: one daemon thread "bot", lives as long as the process. */
public class ExecutorBotScheduler implements BotScheduler {

        Thread thread = new Thread(runnable, "bot");
```

```java
 * around the GameUpdatePublisherPort) and answers with darts on the bot's
 * virtual board. The latest update is the only truth: at most one action is
 * pending, keyed by the game state it was planned for; any other state cancels
 * it, so undo, aborted turns or a human pressing NEXT never cause extra darts.
 *
 * Threading: publish() runs on the tournament thread, actions on the
 * scheduler thread; all state is guarded by this.
 */
public class BotService {

    record ActionKey(int gameId, int playerId, int freieWuerfe, EngineState state) {
        static ActionKey of(EngineUpdate update) {
            return new ActionKey(update.gameId(), update.currentPlayer().id(),
                    update.freieWuerfe(), update.state());
        }
    }

    private record Bot(ThrowModel throwModel, BotStrategy x01, BotStrategy cricket) {
    }

    private final VirtualBoardPort board;
    private final BotTiming timing;
    private final BotScheduler scheduler;
    private final Random random;

    private Map<Integer, Bot> bots = Map.of();
    private EngineUpdate latest;
    private ActionKey pendingKey;
    private BotScheduler.Cancellable pending;
    private ActionKey lastExecutedKey;
    private BotScheduler.Cancellable watchdog;

    public BotService(VirtualBoardPort board, BotTiming timing, BotScheduler scheduler, Random random) {
        this.board = board;
        this.timing = timing;
        this.scheduler = scheduler;
        this.random = random;
    }

    /** @return a publisher that forwards everything to delegate and lets the bots react */
    public GameUpdatePublisherPort observing(GameUpdatePublisherPort delegate) {
        return new GameUpdatePublisherPort() {
            @Override
            public void publish(EngineUpdate update) {
                delegate.publish(update);
                onUpdate(update);
            }

            @Override
            public void publishIdle() {
                delegate.publishIdle();
            }
        };
    }

    public synchronized void startTournament(Map<Integer, BotProfile> botsByBoard, HouseRules houseRules) {
        stopTournament();
        IntPredicate penalized = houseRules.schnapszahlPenalty() ? HouseRules::isSchnapszahl : rest -> false;
        Map<Integer, Bot> created = new HashMap<>();
        botsByBoard.forEach((boardId, profile) -> {
            ThrowModel model = new ThrowModel(profile.sigma(), new Random(this.random.nextLong()));
            created.put(boardId, new Bot(model,
                    new X01Strategy(profile.smart(), model, penalized),
                    new CricketStrategy(profile.smart())));
        });
        this.bots = Map.copyOf(created);
    }

    public synchronized void stopTournament() {
        cancelPending();
        cancelWatchdog();
        this.bots = Map.of();
        this.latest = null;
        this.lastExecutedKey = null;
    }

    synchronized void onUpdate(EngineUpdate update) {
        if (update.currentPlayer() == null) {
            return;
        }
        this.latest = update;
        ActionKey key = ActionKey.of(update);
        if (key.equals(this.pendingKey) || key.equals(this.lastExecutedKey)) {
            return; // duplicate of what is already planned or done
        }
        cancelPending();
        cancelWatchdog();
        if (!this.bots.containsKey(update.currentPlayer().dartboardId())) {
            return;
        }
        Duration delay = delayFor(update.state());
        if (delay == null) {
            return;
        }
        this.pendingKey = key;
        this.pending = this.scheduler.schedule(delay, () -> execute(key));
    }

    private Duration delayFor(EngineState state) {
        return switch (state) {
            case RUNNING -> {
                long spread = this.timing.maxDart().toMillis() - this.timing.minDart().toMillis();
                yield this.timing.minDart().plusMillis((long) (this.random.nextDouble() * spread));
            }
            case WAITING -> this.timing.nextDelay();
            case FINISHED -> this.timing.gameEndDelay();
            default -> null;
        };
    }

    private synchronized void execute(ActionKey key) {
        if (!key.equals(this.pendingKey) && !key.equals(this.lastExecutedKey)) {
            return; // superseded
        }
        this.pending = null;
        this.pendingKey = null;
        EngineUpdate update = this.latest;
        if (update == null || !ActionKey.of(update).equals(key)) {
            return;
        }
        int boardId = update.currentPlayer().dartboardId();
        Bot bot = this.bots.get(boardId);
        if (bot == null) {
            return;
        }
        try {
            if (update.state() == EngineState.RUNNING) {
                BotStrategy strategy = CricketGame.GAME_MODE.equals(update.snapshot().gameMode())
                        ? bot.cricket() : bot.x01();
                Segment hit = bot.throwModel().throwAt(
                        strategy.aim(update.snapshot(), update.currentPlayer().player()));
                this.board.throwDart(boardId, hit);
            } else {
                this.board.next(boardId);
            }
        } catch (RuntimeException e) {
            System.err.println("[BOT] Aktion fehlgeschlagen, Watchdog wiederholt: " + e.getMessage());
        }
        this.lastExecutedKey = key;
        cancelWatchdog();
        this.watchdog = this.scheduler.schedule(this.timing.watchdog(), () -> execute(key));
    }

    private void cancelPending() {
        if (this.pending != null) {
            this.pending.cancel();
        }
        this.pending = null;
        this.pendingKey = null;
    }

    private void cancelWatchdog() {
        if (this.watchdog != null) {
            this.watchdog.cancel();
        }
        this.watchdog = null;
    }
}
```

```js
  function openBotDialog() {
    const presets = BOT_PRESETS.map(([name, average]) => ({
      label: name + ' (Ø ' + average + ')',
      onSelect: () => addBot(average)
    }));
    openModal('Bot hinzufügen', [
      ...presets,
      {
        label: 'Eigene Stärke',
        value: () => 'Ø ' + botAverage,
        onCycle: (delta) => { botAverage = Math.max(0, Math.min(180, botAverage + 5 * delta)); }
      },
      { label: () => 'Bot mit Ø ' + botAverage + ' hinzufügen', onSelect: () => addBot(botAverage) },
      { label: 'Abbrechen' }
    ]);
  }

  async function addBot(average) {
    await call(Api.post('/api/lobby/bots', { average }));
  }
```

```markdown
### Bots

Der Host kann in der Lobby Computergegner hinzufügen (Management-UI „Bot hinzufügen“, TV „+ Bot hinzufügen…“,
REST `POST /api/lobby/bots` mit `{"name"?: "...", "average": 0–180}`). Die Spielstärke ist das
3-Dart-Average (Presets Easy 25, Normal 40, Hard 60, Pro 85); ab Ø 40 spielt der Bot taktisch
(Checkout-Tabelle, meidet Schnapszahlen und Bogey-Zahlen). Bots werfen über ein virtuelles Board
(IDs 900–999, für Menschen gesperrt) via MQTT `dartboard/<id>` und zählen als vollwertige Spieler
(Strafpunkte, Strafgeld, Statistik). Im gameUpdate tragen sie `"bot": true`.
```
